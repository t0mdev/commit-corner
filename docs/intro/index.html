Commit Corner for VS Code

Watch, review, act

Getting the most out of Commit Corner: one slide per view, plus the keys that tie them together.

1 · WATCH
GraphNew commits glow as they arrive. A ✎ 2 chip marks a commit whose worktree has uncommitted work.
2 · REVIEW
Worktrees & PRsChanges vs main, file by file. Space ticks a file as Viewed, and it unticks itself when the agent changes it again.
3 · ACT
Commit, compare, shipStage and commit right in the graph. ✨ writes commit messages and summaries. Push, rebase and cherry-pick are a key away.
It can run next to the built-in Git, or replace it. Everything works by keyboard; every view is in the Commit Corner activity bar icon.

Getting around

Back to the sidebar: the Graph, keyboard in its list (from the editor too)
Ctrl+Alt+G Space
Actions hub: every view and action, searchable
Ctrl+Alt+G G
The full graph in an editor
Ctrl+Alt+G W / T
Worktrees overview / Repository Activity
Ctrl+Alt+G H / L
History of this file / of the selected lines

One view at a time: the layers icon in each view's title bar (Switch View) moves between the six sidebar views.

Graph (sidebar)

Ctrl+Alt+G V: what is going on, newest first

  • Each row: when · who · how much · what, grouped into Today, Yesterday, This week…
  • A blue dot marks commits that arrived while you were away; Ctrl+Alt+G Shift+V shows the changes since you last looked
  • Uncommitted changes on top: → opens a full staging area with a commit box
    • + stages, - unstages, Del discards (a file, a folder or a group); Enter commits
  • → on a commit lists its files; Enter opens the diff

Graph (editor)

Ctrl+Alt+G G: the whole history, with room

  • Columns: author, a +/− bar, age, SHA; the details pane has the full message and actions
  • Select several commits (Shift/Ctrl+click) for a combined diff of exactly those commits
  • Right-click or .: checkout, cherry-pick, revert, reset, rebase, bisect…
  • One click squashes, rewords, drops or fixes up a commit, and Ctrl+Alt+G Shift+U undoes it
  • Ctrl+F searches messages, authors, paths or code changes

Repository

Branches, remotes, tags and stashes in one tree

  • Outgoing / Incoming: what a push or pull would move
  • Local branches with ↑ahead ↓behind and age; Ctrl+Alt+G O checks out any branch
  • Stashes as a group: open, apply, pop; Del drops
  • Ctrl+C copies a name; . shows everything you can do with a branch or tag
  • Fetch, pull, push and sync: Ctrl+Alt+G F / Shift+F / Shift+P / Y

Pull Requests

GitHub pull requests, diffed by git itself

  • Each PR expands to its base, commits and Files changed, diffed from the merge base like GitHub's tab
  • Viewed checkboxes per file; a push that changes a file unticks it
  • Reviews and CI checks when you are signed in to GitHub; without the API it falls back to git ls-remote
  • ✨ Summarize Pull Request: what it does, what looks risky, and what to read first
  • Ctrl+Alt+G P opens a PR's changes, N creates one

Compare

Ctrl+Alt+G C: any two refs, or a ref and your working tree

  • Commits only on each side, grouped by time
  • Files changed since they diverged; Enter opens a diff, or all of them in one multi-diff
  • Swap the sides, or compare against the working tree
  • Also from the graph: select two commits and choose Compare

File History

Follows the file you are looking at

  • Every commit that touched it, renames included
  • Ctrl+Alt+G L: only the commits that touched the selected lines
  • Ctrl+Alt+G ← / → steps through the file's revisions in a diff
  • Ctrl+Alt+G B: blame; I shows the commit of the current line

Worktrees

Where your agents work, and where you review them

  • Each worktree with its uncommitted changes, ↑ahead ↓behind and age, checked again every 10 seconds
  • Changes vs main: everything the agent changed, committed or not
    • Enter shows a diff and keeps the keyboard in the list; Space ticks it as Viewed
  • ✨ Summarize the worktree's work; open all its changes in one multi-diff
  • Ctrl+Alt+G W: the overview, one card per worktree

Repository Activity

Ctrl+Alt+G T: what has been going on

  • Last 7 days, 30 days or 12 months, for all branches or one
  • Commits per day, people, lines and files changed
  • Busiest files, merged pull requests, active branches. Click a person, a file or a pull request to see their commits, history or changes
  • The one-line summary on top of the sidebar Graph opens it

✨ AI, on your terms

With the language model you already use in VS Code

  • Commit messages: ✨ in the commit box writes one from the staged changes, and Ctrl+Z brings back what was there
  • Summaries of a worktree, a pull request or selected commits: what changed, what looks risky, what to read first
  • Before anything is sent, .env and key files are left out and known secrets are removed. The page says what was left out
  • Nothing else leaves your machine: no telemetry, and GitHub is contacted only for pull requests

Habits that pay off

Let agents work in worktreesEach agent gets its own folder and branch. You watch them in the Graph (the ✎ chip) and review them in Worktrees, without stashing your own work.
Review with ViewedEnter to read, Space to tick. A file the agent touches again comes back unticked, so nothing slips through.
Commit from the graphExpand Uncommitted changes, stage with +, write or ✨ the message, press Enter. Source Control shares the same message.
Undo is one keyA squash, reword or drop went wrong? Ctrl+Alt+G Shift+U puts the branch back.

Press ? in a graph for its keys · Ctrl+Alt+G Space for everything else
