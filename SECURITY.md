# Security policy

Please report vulnerabilities **privately** through GitHub's
[private vulnerability reporting](https://github.com/t0mdev/commit-corner/security/advisories/new),
not in a public issue.

Include the version, the steps to reproduce and what an attacker could gain. Commit Corner
is maintained in spare time: there is no guaranteed response time. Fixes are released as a
new version on the [Releases](https://github.com/t0mdev/commit-corner/releases) page.

Only the latest release is supported.

What the extension may do (git, the optional GitHub API requests, language models only
when you ask) is described under *Scope and privacy* and *Security* in the
[README](README.md).
