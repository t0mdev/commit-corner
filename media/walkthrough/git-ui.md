# One Git UI

VS Code's built-in Git is still on, so Source Control lists every repository twice. Commit Corner replaces it for staging, commit, sync, blame and merge conflicts.

**Use Commit Corner Only** sets `git.enabled` to false for you; you can turn it back on in Settings at any time. Extensions that rely on the built-in Git API (such as GitHub Pull Requests) then no longer see your repositories.
