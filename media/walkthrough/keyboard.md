# Everything by keyboard

- `Ctrl+Alt+G Space` — the **Actions hub**: every action, searchable.
- `Ctrl+Alt+G V` — the sidebar graph · `Ctrl+Alt+G G` — the graph in an editor
- `Ctrl+Alt+G W` — the worktrees overview · `Ctrl+Alt+G T` — repository activity
- `Shift+F10` (or `.` in the graph) — the actions of what is selected.

All chords start with `Ctrl+Alt+G` (`Cmd+Alt+G` on macOS); the full list is in the README.
